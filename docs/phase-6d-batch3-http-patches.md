## Security and regression evidence

Local `npm ci --ignore-scripts` succeeded under Node 24.22.1/npm 11.9.0; the Actions workflow pins Node 24.21.0 and validates npm 11.19.0. The focused test exercises bounded JSON and URL-encoded input, malformed and oversized JSON, gzip including trailing bytes and decompressed size, continued server operation, same- and cross-host redirect credential handling (including array headers and custom sensitive-header regex escaping), loop and timeout handling, forged forwarded-IP identity, IPv6 key normalization, multipart SDK form-data headers and CRLF escaping in filenames and field names, and Mammoth extraction with valid, malformed XML/archive, and large controlled DOCX fixtures. Existing tests cover Better Auth, business/tenant limits, production proxy CIDRs, upload staging gate, queue retries/cleanup, worker ownership, JSON/SSE chat, and mocked provider integrations. No external paid provider or live uploaded file was used. The parser fixture is a small Express app with a 1 KiB test limit, not the deployed API/ingress; the `form-data` regression exercises the shared encoding library, not an end-to-end provider request; the redirect test uses local hosts, not deployed provider egress.

Local full test suite: 191 total, 188 passed, 0 failed, 3 skipped because isolated PostgreSQL/Redis fixtures are not available locally. Targeted parsing, IP identity, proxy, upload security, quota and worker tests: 67 passed, 0 failed/skipped. The repository `security-tests.yml` runs with PostgreSQL 16/pgvector and Redis 7 and provides the authoritative integration count.

Using the Phase 6C sanitizer on four freshly generated JSON reports under the above local Node/npm: full audit **0 critical / 14 high / 9 moderate / 0 low** (23 records), production **0 / 13 / 9 / 0** (22 records), versus Batch 2 full **0 / 19 / 10 / 0** and production **0 / 18 / 10 / 0**. `npm audit` full/production exited 1 because other advisories remain; `npm ls --all` exited 0; `npm outdated` exited 1. All four reports parsed and passed schema/redaction validation. Six package records disappeared, including the inherited `express-rate-limit` record; five were high and one moderate. These record counts are not distinct advisory counts. The audit feed may change; use the CI artifact's timestamp and actual counts as final evidence.

The remaining production high package records are `@browserbasehq/stagehand`, `@langchain/community`, `@langchain/core`, `@langchain/openai`, `axios`, `ibm-cloud-sdk-core`, `js-yaml`, `langchain`, `langsmith`, `openai`, `undici`, `ws`, and `zod` (including inherited metavulnerabilities). Other moderate findings remain. There were no newly introduced critical/high package records in the local comparison. A later batch should independently examine compatible `js-yaml`, `undici`, and `ws` patches, followed by Axios/IBM parent pinning and major LangChain/Zod/OpenAI migrations with their own runtime and provider contract tests.
